# NeroNotes Wiki

Player- and contributor-facing documentation for **NeroNotes**, part of the
Neroland ecosystem. Built on **Neroland Core**.

> **Status:** in development (version `0.0.1-alpha.1`) — Resonant Blocks and Resonators with
> synchronised channel playback, the Harmonic Gate and Soundforge composing dimension, and now the
> full composing loop: the sequencer at the transport lectern, pattern walls and voice pedestals,
> blank disks and the Disk Press. Block textures are generated placeholders and all sounds
> alias vanilla sound events for now. Pages will grow as features land. Keep this wiki updated
> alongside code changes (see [`../AGENTS.md`](../AGENTS.md) / [`../CLAUDE.md`](../CLAUDE.md)).
